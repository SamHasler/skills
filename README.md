# skills

Sam Hasler's Claude Code plugins, published as a plugin marketplace. Each plugin installs separately.

```
/plugin marketplace add SamHasler/skills
```

| Plugin | What it does |
| --- | --- |
| [reference-points](plugins/reference-points/README.md) | Short codes for questions, decisions, options, findings, risks, steps and actions, an end-of-turn status update, and numbering that survives compaction. |
